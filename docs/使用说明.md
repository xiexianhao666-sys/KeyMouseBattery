# 使用说明

## 1. 安装与启动

1. 把 `键鼠电量-0.3.1-dev-win64.zip` 解压到普通文件夹，例如 `D:\Apps\KeyMouseBattery`。
2. 双击 `KeyMouseBattery.exe`。程序启动后面板会打开，托盘出现一个圆形数字图标。
3. 关闭面板不会退出程序；退出请在托盘右键菜单里选「退出」。

> 除「开机启动」这一项会在你手动开启时写 `HKCU\...\Run` 外，程序不读注册表、不写 `%LOCALAPPDATA%`、不装系统服务；删掉文件夹即完全移除。

### 关于「未知发布者」提示

本版可执行文件**未做代码签名**（构建产物状态为 NotSigned）。首次运行 Windows 可能弹出 SmartScreen 的「Windows 已保护你的电脑 / 未知发布者」，需要点「更多信息 → 仍要运行」。

这**既不是病毒的证据，也不代表安全**：没有签名意味着你无法用数字证书核对发布者。若你从非本仓库渠道拿到这个包，请先核对随包的 SHA-256 再决定是否运行。

## 2. 面板

- 顶部显示设备总数与在线数。
- 每张卡：设备名、品类与连接方式、大号电量、状态（已连接 / 上次读数 / 未连接）、更新时间。
- 没有读数时显示 `—`，不会显示 0%。
- 「立即刷新」立即触发一轮读取。

## 3. 托盘

- 图标显示数字电量；未知时显示空心环。
- 左键：打开 / 收起面板。
- 右键菜单：打开面板、立即刷新、退出。

## 4. 电量口径

| 情况 | 显示 |
| --- | --- |
| 正常读数 1–100 | `86%` |
| 读到 0 或越界 | `—`（原始值写进日志） |
| 设备休眠/断开，且有旧读数 | 旧值 + 「上次读数」 |
| 设备休眠/断开，且无旧读数 | `—` + 「未连接」 |
| 充电状态 | 只有协议提供充电位时才显示；蓝牙为「充电状态未知」 |

## 5. 数据文件

- `data\config.json`：刷新间隔、低电量阈值、蓝牙设备名关键字等。
- `data\keymousebattery.log`：运行日志，轮转 3 份、每份上限 512 KB。
- `data\tmp\`：临时文件目录（用于生成托盘图标位图）。

## 6. 常见问题

**面板里没有我的设备？**
确认设备已在 Windows「蓝牙和其他设备」里配对，且当前处于连接状态；键盘若用 2.4G 接收器，请按一下键盘让它醒着。

**托盘图标不出现？**
请从解压后的普通文件夹直接双击 exe，不要以管理员身份运行、也不要从受限目录启动。

**能读到 100% 但不确定准不准？**
本阶段只保证「读数来自设备协议」，没有与厂商软件的显示做对照；需要对照时请看设备自身指示灯或厂商软件。

## 6. 设置与桌面电量条（0.3.1-dev）

设置页五项，保存后立即生效：

| 项目 | 可选值 | 说明 |
| --- | --- | --- |
| 刷新间隔 | 30 / 60 / 120 / 300 秒 | 默认 60 秒 |
| 低电量提醒 | 关闭 / 10 / 20 / 30% | 默认 20%；关闭后不再弹提醒（卡片仍按 20% 变色） |
| 托盘图标 | 数字 / 电池 | 默认数字；深色任务栏自动换白色描边 |
| 桌面电量条 | 开 / 关 | 默认关闭；开启后出现 键盘 100% │ 鼠标 100% 小窗 |
| 开机启动 | 开 / 关 | 默认关闭；只有便携包（exe）能注册 |

低电量提醒规则：在线且有效读数跨过阈值时提醒一次；回到「阈值 +5」以上才重新武装；断连旧值、未知读数不提醒。

桌面电量条可拖动到任意位置并记住；点击它打开面板；位置在多屏或 DPI 变化后会自动夹回可见区域。

开机启动会写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\KeyMouseBattery`，值为带引号的绝对路径加 `--background`。注册失败会恢复开关并提示原因；移动程序目录后需要重新开启。
